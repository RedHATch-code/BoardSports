BoardSports.

Plataforma web de comunidade para desportos de prancha: surf, skate, skimboard, snowboard e sandboard. O projeto permite descobrir spots, publicar vídeos, criar perfis, ganhar XP e participar num ranking de riders.

Ideia principal

A BoardSports nasce para juntar riders e spots reais numa só plataforma. Em vez de ser apenas uma página informativa, o site funciona como uma comunidade onde cada utilizador pode explorar locais, contribuir com conteúdo e acompanhar a sua evolução através de XP.

Problema

Informação sobre spots de surf, skate, skimboard, snowboard e sandboard costuma estar espalhada por redes sociais, mapas genéricos ou recomendações informais. Isso dificulta encontrar locais, perceber a dificuldade e ver exemplos reais de sessões.

Solução

O projeto centraliza spots, vídeos, perfis e rankings numa aplicação web simples, acessível e explicável no contexto da PAP, sem recorrer a frameworks pesadas ou arquitetura desnecessária.

Funcionalidades

  • Landing page de apresentação da comunidade BoardSports.
  • Mapa interativo com Leaflet.js para visualizar spots.
  • Filtros por modalidade, categoria, país e criador.
  • Criação e edição de spots com localização geográfica.
  • Publicação de vídeos associados a spots.
  • Login, registo, recuperação de password e verificação de email.
  • Perfis de utilizador com publicações, estatísticas e XP.
  • Leaderboard para destacar riders ativos.
  • Painel de moderação/admin para validação de conteúdo.
  • Páginas institucionais: contacto, termos, privacidade e sobre.

Tecnologias

  • HTML5 para a estrutura das páginas.
  • CSS3 para layout, responsividade e identidade visual.
  • JavaScript modular para interatividade.
  • Leaflet.js para o mapa interativo.
  • Supabase/Postgres para autenticação e dados.
  • Netlify para alojamento e deploy.

Base de dados

A base de dados guarda utilizadores, perfis, modalidades, categorias, spots, vídeos, XP, submissões e dados usados pela moderação. As migrations Supabase permitem documentar e recriar a estrutura do projeto.

Utilizadores

O público-alvo são praticantes e interessados em board sports, desde iniciantes que querem descobrir locais até riders experientes que querem partilhar sessões e contribuir com informação útil.

Administração

A moderação permite controlar publicações, validar conteúdo e reduzir informação incorreta. Esta camada é importante porque o projeto depende de dados enviados pela comunidade.

Fluxo de uso

  1. O utilizador entra no site e explora a ideia geral da plataforma.
  2. Abre o mapa para descobrir spots por modalidade.
  3. Cria conta ou inicia sessão para contribuir.
  4. Adiciona spots, publica vídeos ou submete provas.
  5. Ganha XP e aparece no ranking da comunidade.
  6. O administrador valida e gere conteúdo no painel de moderação.

Pontos fortes

O projeto junta mapa, comunidade, vídeos e gamificação numa aplicação coerente. A estrutura é simples de explicar, mas suficientemente completa para demonstrar frontend, base de dados, autenticação e deploy.

Limitações

Algumas funcionalidades dependem da ligação ao Supabase e das permissões da base de dados. No futuro, o projeto pode melhorar a moderação, adicionar upload direto de imagens/vídeos e criar uma experiência mobile ainda mais polida.

Conclusão

A BoardSports mostra como uma aplicação web pode resolver uma necessidade concreta de uma comunidade. O resultado final apresenta uma plataforma funcional, visualmente ligada à cultura surf/skate e com espaço para crescimento futuro.
